Setup

  1. 1
    Show the bookmarks bar

    Press Ctrl + Shift + B in Chrome.

  2. 2
    Save Picker

    Drag the Picker Bookmark v1 button to the bookmarks bar.

  3. 3
    Open Manual Match

    Navigate to a Store or Retail Manual Match record.

  4. 4
    Start Picker

    Click the saved bookmark. Use Kill Bot when the check is finished.

Google integration: Address Search and Maps open in separate tabs. Automatic phone and business-status collection is not included.
