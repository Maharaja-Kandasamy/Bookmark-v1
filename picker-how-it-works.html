MANUAL MATCH

How Picker works

Use Picker on the Store or Retail Manual Match screen to search the current record and review possible duplicates.

Run a search

  1. Open Picker using your saved bookmark on a Manual Match screen.
  2. Choose Banner, Address, Phone, Store number or All above the robot.
  3. Picker minimizes while searching. Click the robot to open the results panel.
  4. Review candidates and their record status before copying information.

Choose the right control

ControlWhat it searches
B · BannerExact and wildcard banner with ZIP3.
A · AddressWildcard address with city and ZIP3.
P · PhoneThe last seven digits of the phone number.
S · StoreStore number with a wildcard banner.
AllRuns every search group sequentially.

Review and copy

Results distinguish direct, exact, high-confidence and partial candidates. TD Copy and Full Copy apply to the selected candidate. Copy Store Data copies the source record. Google and Maps controls open normal external search links.

When the record changes

Picker watches the source table, resets results when you move to another record and cancels the previous record’s searches. Every run rescans the current record.

Search values and broader matches

Search automation temporarily selects the filters needed for each query, then restores the original values and selections after completion or cancellation. It does not restore an old record’s search values after you move to another record.

Wildcard searches simplify common road types, directions, unit details and company suffixes. Broader searches can return extra candidates, so review the results before using them. Original source values and copies remain intact.

Close Picker

Use Kill Bot to stop searches immediately and remove the robot. Clicking the bookmark again opens a fresh instance. Replace your saved bookmark when installing an update.
